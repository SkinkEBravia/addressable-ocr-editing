## 1. 编辑接口在中心趋势上不可分，在尾部差 33 倍

中位数跨度 0.0084~0.0120（**1.4×**），max 跨度 0.0295~0.9648（**33×**）。

`pfr` 与 `fr-numkey` 中位几乎相同（0.0084 / 0.0087），p90 差 **2.8×**（0.0199 / 0.0564）。

六个层叠对照有四个 CI 跨 0 —— **在 n=33、单模型下，接口差异在中心趋势上分辨不出来。**

与 coding-agent 文献一致（`execute_code regime`，arXiv:2607.10569 §6.3：
"Pass rates differ by less than three percentage points across every cell"），
但那里的指标是 pass/fail 二值的，**看不见尾部**。本批次是同一结论加上尾部维度。

批次 1 已有同型证据（`dta19-doc-1t`：`swe_edit` max 0.2579 vs `find_replace` 0.0090），
本批次在统一提示词、统一视图、逐级单变量的设计下复现。

## 2. `rewrite` 的失败是灾难型的，加 key 能压住

`rewrite` max **0.9648**（单篇几乎全毁），broken 3.86%。
加 num-key 后 max 降到 0.0322、broken 降到 0.82%，是两个显著对照之一。

⚠️ 该显著性由**单个样本**驱动，措辞需克制。

## 3. num-key 光是被看见就改变行为

`find-replace` → `fr-numkey` 只加了视图里的编号（模型用不上），
`fixed` 掉 **10.3pp**（61.3%→51.0%），`edit_spans` 掉 36（254.5→218.2）。

**看到一堆编号，模型就变保守了。**

⇒ 批次 1 中「带标记臂 vs 不带标记臂」的比较**不可比**（呈现本身是混淆项）。

## 4. 同一对照的均值与中位数符号相反

`find-replace` → `fr-numkey`：均值 0.0139→0.0172（变差，且显著），
中位 0.0096→0.0087（**变好**）。33 篇中 16 篇变差、17 篇变好，
两篇 l2 样本拉了 +0.043 / +0.049。

**符号取决于口径。** 任何单一统计量都不足以描述这个分布，必须中位与尾部并列。

## 5. 注意力控制对 `find_replace` 是净亏

`fr-numkey` → `fr-blocked`：`fixed` −3.0%，`broken` 不降（0.39%→0.38%），
out token **+21%**（2.13M→2.58M）。

对 `patch` 才略有帮助（`fixed` +2.1%，中位 0.0089→0.0084），但同样 CI 跨 0。

⇒ **「先按块想再发散」的收益依赖操作面，不是通用增益。**

## 6. 稳定 key 优于不稳定，但未达显著

`pfr` → `pfr-unstable`（key 每次编辑后重排，外观完全相同）：
中位 0.0084→0.0104，`fixed` −6.3%，Δcmer +0.00168 **[−0.00026, +0.00388]** —— 擦边跨 0。

方向支持 num-key 的设计前提（不稳定 key 迫使模型预判自身编辑造成的位移），
但**证据强度不足以下断言**。

## 7. `key_leak` 全场 0.00%

八个单元无一泄漏 —— 「`rewrite` 最可能把 key 抄进产出」的预期落空。
共享 view description 里那句 `never include them in what you output` 起了作用。

## 缺口

**单模型。** 全部结论目前是 `volc-deepseek-v4-flash` 的性质，不是编辑接口的性质。
第二个模型（8 单元 ≈ 18M token）是把这批数据从"实验记录"变成"发现"的必要条件。

**尾部只报了 max / p90，未做检验。** 第 1 条是本批次最强的结论，但目前只有描述统计。
